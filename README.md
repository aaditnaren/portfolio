# Aadit Narendar — Complete Swarm Site

An independent particle-only storytelling site for Aadit Narendar, Intelligence Architect.

Only the name and professional title use visible DOM text. All narrative lettering, metrics, illustrations, and progress indicators are sampled or generated as particles on a shared canvas. Two wider, opposing rings open the story. Subsequent scenes cover healthcare, agentic automation, catalog intelligence, enterprise AI, visual creation, leadership, and contact.

## Live Preview
Deployable via GitHub Pages.

## Local Development
To test locally, run:
```bash
npm run dev
```
Then open `http://localhost:4173`.

## Verification
Run syntax and canvas simulation tests:
```bash
npm run check
```
